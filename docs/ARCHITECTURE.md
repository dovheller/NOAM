# ארכיטקטורה

> טיוטה. הנחת העבודה: ממשק ווב מקומי (ראו WP0 ב-`ROADMAP.md`). אם יוחלט על דסקטופ, משתנה רק `ui/`.

## רכיבים

```
┌──────────────────────── עמדת המפעיל (מחשב) ────────────────────────┐
│                                                                     │
│  device/ ──▶ copy/ ──▶ report/                                      │
│  (MTP)       (SHA-256)  (PDF חתום)                                  │
│     │           │          │                                        │
│     └───────────┴────┬─────┘                                        │
│                 session/  ──▶  audit log (מטא-דאטה בלבד)             │
│                      │                                              │
│                 privacy/   ◀── כל מה שיוצא למפעיל עובר כאן            │
│                 │        │                                          │
│        ui/operator/   ui/client/ ──── רשת מקומית סגורה ────▶ טאבלט  │
│        (ספירות בלבד)   (תוכן — ללקוח בלבד)                           │
└─────────────────────────────────────────────────────────────────────┘

┌──────── לפטופ שכבה 2 (נפרד) ────────┐
│  noam_l2/  triage → collect → key   │
│            → decrypt → export → wipe│
└─────────────────────────────────────┘
```

## מודולים

| מודול | אחריות | חבילת עבודה |
|---|---|---|
| `session/` | מצבי הסשן, פרטי תיק, יומן audit | WP1 |
| `device/` | זיהוי מכשיר וקריאה דרך MTP | WP2 |
| `copy/` | העתקה, אימות, מניפסט, יעדים | WP3, WP4 |
| `report/` | דוח PDF חתום | WP5 |
| `privacy/` | מסנן הנתונים לצד המפעיל | WP6 |
| `ui/operator/` | קונסולת המפעיל | WP7 |
| `ui/client/` | טאבלט הלקוח | WP8 |
| `noam_l2/` | שכבה 2 — WhatsApp | WP11, WP12 |

## זרימת נתונים
1. המפעיל פותח סשן ← הטאבלט עובר לבחירת שפה.
2. `device/` סורק ← `privacy/` מעביר למפעיל ספירות בלבד, וללקוח את העץ המלא.
3. הלקוח בוחר וחותם בטאבלט.
4. `copy/` מעתיק ומאמת ← התקדמות לשני הממשקים.
5. `report/` מפיק דוח חתום ← הסשן נסגר והיומן נחתם.

## אחסון
- יעד הלקוח: מה שנבחר (SSD, SD, ענן).
- בעמדה: יומני audit, מניפסטים ודוחות בלבד. **אין עותק של תוכן לקוח בעמדה.**
