# מדריך מפעיל — עמדת NOAM

> לנועם. עדכון: 2026-11-10. מסמך עבודה יומיומי; ההתקנה ב-`INSTALL.md`.

## תחילת יום
1. הדלק את העמדה. הזן את **סיסמת הדיסק** (LUKS).
2. הקונסולה עולה לבד. עבור ל**הגדרות** ← הזן קוד ← **פתח את מפתח החתימה** (הסיסמה שלך או של דב). בלי זה, הדוחות לא ייחתמו.
3. **אבחון** — כל הכרטיסים ירוקים? בדוק את השעון מול הטלפון שלך. מקום פנוי ביעד מעל 50GB.

|---|---|---|

| 2 | "הטאבלט במסך בחירת שפה" | הלקוח בוחר שפה |

| 5 | ספירות לפי קטגוריה וקבוצות (g01…) — **בלי שמות** | הלקוח רואה את התיקיות שלו ובוחר מה להעביר |

## כשמשהו משתבש
| מה רואים | מה עושים |
|---|---|
| מכשיר "לא נגיש · ERR_ADB_UNAUTHORIZED" | צריך ללחוץ "אפשר" על מסך הטלפון. מסך שבור — עכבר OTG |
| "לא נגיש · ERR_NO_STORAGE_VISIBLE" / הטלפון לא מופיע | הטלפון נעול, או לא נבחר "העברת קבצים". בקש מהלקוח לפתוח ולבחור שוב. **סרוק עכשיו** |
| הסשן "בוטל · ERR_DEVICE_DISCONNECTED" | הכבל זז. **לא נמחק כלום.** סגור את הסשן (אפשר להפיק דוח חלקי), ופתח חדש. בתיק חדש הקבצים שכבר אומתו יועתקו שוב |
| "ERR_TARGET_SPACE" | הדיסק מלא. החלף דיסק יעד |
| "ERR_TARGET_WRITE_TEST" | דיסק היעד לא מחובר או מוגן מכתיבה |
| דילוגים (ERR_READ_FAILED) | קבצים בודדים שהטלפון לא החזיר. רשומים בדוח. אפשר לנסות שוב בסשן נפרד |
| "מפתח החתימה נעול" | הגדרות ← סיסמת מנהל |
| "נחסם: המסך עמד להציג תוכן של לקוח" | באג — המערכת עצרה את המסך כדי לא להציג לך תוכן. רשום את השעה ודווח לדב |

## מה אסור
- לפתוח קבצים של לקוח, גם אם הוא מבקש "תראה רגע". **הלקוח** רואה בטאבלט.
- לחבר את העמדה לאינטרנט.
- להשאיר את הדוחות או הדיסקים של לקוחות על השולחן.

## מסך נועם
טרמינל לבדיקות מהירות: `help`, `status`, `scan`, `report`, `close`. פקודות תוכן (`ls`, `cat`, `open`…) חסומות **ונרשמות ביומן**.

## סוף יום
- היסטוריה ← ודא שכל הסשנים סגורים.
- כבה את העמדה (המפתח נסגר עם הכיבוי).
