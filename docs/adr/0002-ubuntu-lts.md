# ADR 0002 — מערכת הפעלה לעמדה: Ubuntu LTS

**סטטוס:** מוצע

## הקשר
העמדה ניגשת לטלפונים ב-MTP, מעתיקה, חותמת ושומרת יומני audit. היא צריכה להיות צפויה, ולא לדבר החוצה.

## חלופות
| חלופה | בעד | נגד |
|---|---|---|
| **Ubuntu LTS** | `libmtp` בוגר; udev; `blockdev --setro`; `sha256sum`/`openssl` נייטיב; קל לוודא שאין תעבורה החוצה | המפעיל לא מכיר; כלים קודמים נכתבו ל-Windows |
| Windows | מוכר; WPD עובד | COM והרשאות; סנכרון ענן ועדכונים ברקע קשים לנטרול |
| macOS | — | אין MTP נייטיב |

## החלטה
Ubuntu LTS: משתמש ייעודי, בלי אינטרנט, דיסק מוצפן (LUKS), מפתח החתימה ב-TPM אם החומרה תומכת (ראו `docs/SECURITY.md`).

## השלכות
- המפעיל עובד רק דרך הממשק בדפדפן, אף פעם לא בטרמינל. העמדה עולה ישר לדפדפן במצב קיוסק.
- הלקחים בנושא Windows (bidi בטרמינל, Phone Link) רלוונטיים רק לכלים הישנים.
- WP10 כולל מתקין או image מוכן לעמדה.
