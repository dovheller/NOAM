# ADR 0001 — ממשק: ווב מקומי

**סטטוס:** מוצע

## הקשר
יש שני ממשקים: קונסולת המפעיל (מחשב) וטאבלט הלקוח. המוקאפ כתוב ב-HTML. כלים קודמים נבנו ב-tkinter.

## חלופות
| חלופה | בעד | נגד |
|---|---|---|
| **ווב מקומי** (שרת Python על localhost + דפדפן) | הטאבלט הוא ממילא דפדפן; המוקאפ ממשיך כמעט כמו שהוא; ממשק אחד לשני המסכים | שרת נוסף להקשיח |
| דסקטופ (tkinter / Qt) | בלי שרת, בלי רשת | הטאבלט צריך אפליקציה נפרדת; עיצוב RTL קשה יותר |

## החלטה
ווב מקומי: שרת **FastAPI** בעמדה, דפדפן בעמדה ובטאבלט.

## השלכות — חובה לקרוא לפני WP2
- **הדפדפן לא ניגש ל-MTP ולא לדיסק.** כל גישה לטלפון (`libmtp`) ולדיסקים נעשית בשרת, בתוך `src/noam/device/` ו-`src/noam/copy/`. לא מחפשים פתרון בצד הדפדפן (WebUSB, File System Access API).
- הדפדפן מקבל רק JSON מה-API. ה-API של המפעיל עובר כולו דרך `noam.privacy`.
- השרת מאזין רק לממשק הרשת הסגורה (ADR 0003) ול-localhost.
