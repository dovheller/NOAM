# התקנת עמדת NOAM

> קהל: מי שמקים את העמדה (דב, או טכנאי בהנחייתו). עדכון: 2026-11-10.
> **לא אומת על חומרה.** כל שלב כאן נכתב לפי התיעוד של Ubuntu 24.04 ושל הרכיבים, ולא הורץ עדיין על המחשב של העמדה. ההתקנה הראשונה היא גם הבדיקה — לרשום כל סטייה ולעדכן כאן.

## מה צריך

| רכיב | הערה |
|---|---|
| מחשב לעמדה | x86-64, 8GB RAM, SSD פנימי 256GB+, שתי יציאות USB 3 לפחות, TPM 2.0 אם יש (SECURITY.md §1) |
| מסך מגע או מסך + מקלדת/עכבר | לקונסולת המפעיל |
| דיסק יעד חיצוני | בתווית `NOAM-SSD`, exFAT |
| ראוטר נפרד | **לא מחובר לאינטרנט**. רשת `10.77.0.0/24`, העמדה ב-`10.77.0.1` |
| טאבלט ללקוח | כל טאבלט עם דפדפן. נעול על `http://10.77.0.1:8000/client` (ראו "הטאבלט") |
| קורא כרטיסי SD | לכרטיסים שנשלפים ממכשירים מתים |
| כבלים | USB-C, Micro-USB, Lightning (לעתיד) |

## שלב 1 — מערכת ההפעלה (Ubuntu 24.04 LTS, מוצפן)

1. הורד את Ubuntu Server 24.04 LTS (ISO) וצרוב ל-USB.
2. ערוך את `deploy/autoinstall/user-data`:
   - `password` — hash של סיסמת מנהל המערכת: `mkpasswd -m sha-512`.
   - `storage.layout.password` — סיסמת הצפנת הדיסק (LUKS). תוזן בכל הדלקה. **לשמור** — בלעדיה הדיסק אבוד.
3. העתק את `user-data` ואת `meta-data` (ריק) ל-USB שני בשם `CIDATA`.
4. אתחל מה-ISO כששני ה-USB מחוברים. ההתקנה אוטומטית (כ-15 דקות, צריך אינטרנט בשלב הזה בלבד).

## שלב 2 — NOAM

על העמדה, עם עותק של הריפו (git clone או USB):

```bash
sudo ./deploy/install.sh
```

הסקריפט יוצר משתמשי שירות, תיקיות מוגנות, סביבת Python, חוקי udev, שירותי systemd, חומת אש, ו-`/etc/noam/config.toml`. בסוף הוא מדפיס חמישה צעדים ידניים:

1. **הגדרות** — `/etc/noam/config.toml`: שם, כתובת, טלפון, `operator.pin` (קוד לאזור ההגדרות).
2. **מפתח חתימה** — דב ונועם יחד. כל אחד שומר את הסיסמה במנהל הסיסמאות שלו. את `station.pub.pem` ו-`station.crt` שומרים גם מחוץ לעמדה — לאימות דוחות בעתיד.
3. **דיסק היעד** — `sudo noam-mark-target /media/noam/NOAM-SSD` (בלי הסימון הדיסק עלול להופיע כ"מקור").
4. **רשת** — כתובת קבועה `10.77.0.1/24` (netplan) לכרטיס שמחובר לראוטר הסגור.
5. **אתחול.**

## שלב 3 — הטאבלט

- מחובר לרשת ה-Wi-Fi של הראוטר הסגור בלבד.
- דפדפן במסך מלא על `http://10.77.0.1:8000/client`, נעול לאפליקציה אחת (באנדרואיד: "הצמדת מסך" / Screen pinning; או אפליקציית קיוסק). **החלטה פתוחה לדב:** איזה טאבלט ואיזה מנגנון נעילה.
- אם רוצים שרק הטאבלט יגיע לממשק הלקוח: `tablet_hosts = ["10.77.0.20"]` ב-config, וכתובת קבועה לטאבלט בראוטר.

## מה רץ אחרי ההתקנה

| שירות | מה הוא עושה |
|---|---|
| `noam-firewall` | nftables: שום דבר לא יוצא; רק הרשת הסגורה נכנסת לפורט 8000 |
| `noam-station` | השרת (משתמש `noam-svc`, מערכת קבצים לקריאה בלבד חוץ מ-`/var/lib/noam` ו-`/media/noam`, חסימת רשת ברמת systemd) |
| `noam-kiosk` | `cage` + Chromium במסך מלא על הקונסולה, בלי שורת כתובת |
| `noam-automount@` | כל כרטיס/דיסק של לקוח נטען **לקריאה בלבד** (`ro,noexec,nosuid,nodev`) |

## בדיקות אחרי התקנה (לרשום תוצאה)

```bash
systemctl status noam-firewall noam-station noam-kiosk
sudo nft list ruleset                      # policy drop ב-input וב-output
curl -m 5 https://example.com              # חייב להיכשל
mtp-detect | head                          # עם טלפון מחובר
cd /opt/noam && sudo -u noam-svc ./venv/bin/pytest -m mtp   # בדיקת חומרה, עם טלפון
```

ואז סשן מלא עם טלפון אמיתי: פתיחה בקונסולה ← שפה וחיבור בטאבלט ← בחירה ← חתימה ← העתקה ← דוח ← סגירה.

## לא אומת (לבדוק בהתקנה הראשונה)
- `cage` + Chromium מ-snap על Ubuntu Server 24.04 (snap ו-Wayland ב-cage — ידוע כרגיש). חלופה: `ubuntu-frame`.
- `noam-automount@` — שהטעינה מגיעה לתוך מרחב השמות של `noam-station` (ProtectSystem).
- חוקי udev ל-MTP עם משתמש שירות שאינו מחובר למסך.
- `IPAddressAllow` של systemd ביחד עם nftables.
